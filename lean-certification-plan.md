# Lean certification plan

**Current formal coverage is zero.** PaperMill can audit this plan independently of publication. The unconditional reduction is the first target. The external subexponential contraction premise is a separate dependency.

| Stage | Statement and representation | Acceptance test |
| --- | --- | --- |
| C1. Specify the input and target | Finite port-indexed multigraphs. Every edge has two incidences and exactly one Boolean label. A loop feeds the same label to two ports. Represent each factor by a total table, permit parallel edges, empty products and scalar factors, and record the explicit bit length. | Translate the paper's theorem into a statement about an oracle algorithm and explicit query encodings. Record which parts require complexity formalization beyond the finite algebra. |
| C2. Certify multiplicity and gluing | For a fixed block boundary, enumerate internal edges, reduce the whole sum modulo the inner modulus, and compare a private unsigned word to its least representative. Prove the count of words below the threshold. Factor finite sums across blocks. | The count of the constructed unweighted network is congruent to the *outer-reduced integer contraction* for each inner modulus. Include zero threshold, a loop, a scalar and equality subdivision with its unique extension. |
| C3. Certify reconstruction | Prove the lcm lower bound, prime-power size and coprimality, outer height bound, inner nonnegative uniqueness and final centered uniqueness. | Compose C2 with two CRT reconstructions for arbitrary signed tables. Permit shared primes between the two bases and prove signed output equality from the source tables. |
| C4. Certify the reduction's costs | Account for the small-network branch, block and counter widths, explicit truth-table construction, serial queries, answer lengths and bit costs of generating prime powers and CRT. | Obtain polynomial oracle time with linear wires per instance and logarithmic target arity. A correctness theorem without these bounds covers only the algebraic part of Theorem 1. |
| C5. Conditional consequences | State the pinned external Boolean contraction theorem as an explicit hypothesis. Instantiate its degree and precision parameters. Separately formalize folding, detached factors, cyclotomic accumulators, the exact probability and cut-based depth application. | Track the reduction and each corollary separately. Attribute every assumption, identify which runtime model is certified and audit the resulting axioms. |

**First bounded job.** After PaperMill's usual admission, take one small finite network with an arbitrary partition and prove the C2 congruence by finite sums. Stop and report an interface mismatch if the representation allocates independent bits to a loop's two ports or the block modulus is inadvertently applied to the signed source before the outer reduction. Record imports, theorem statements, toolchain, kernel replay and assumption set before widening the scope. No certification job is running as part of this release.
